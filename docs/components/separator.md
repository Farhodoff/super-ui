# Separator

Visually or semantically separates content in a layout.

## Usage

```tsx
import { Separator } from '@/components/ui/separator'

<div>
  <h4>Section 1</h4>
  <Separator className="my-4" />
  <h4>Section 2</h4>
</div>
```

## API Reference

### Separator Props
- `orientation` (`"horizontal" | "vertical"`): Direction of separator. Defaults to `"horizontal"`.
- `decorative` (`boolean`): Whether purely decorative. Defaults to `true`.

## API Reference

### Separator Props

This component extends standard HTML attributes for its element type. No specific custom props are defined in a named interface.
